# 🧠 MindPatterns | Mood & Behavior Tracker (Vue.js)

Aplicación web interactiva desarrollada con **Vue 3** diseñada para el registro diario del estado de ánimo y el descubrimiento de patrones de comportamiento y correlaciones emocionales.

## 🎯 Propósito del Proyecto
Permitir a las usuarias registrar sus emociones diarias junto con actividades/factores clave (sueño, ejercicio, trabajo) para analizar de forma reactiva cómo sus hábitos impactan su salud mental.

## 🛠️ Tecnologías Utilizadas
- **Vue.js 3** (Composition API con `<script setup>`)
- **Vite** (Build tool)
- **HTML5 & Pure CSS3** (Diseño responsivo minimalista)
- **LocalStorage API** (Persistencia de datos local)

## ⚡ Conceptos de Vue Aplicados
- **Reactividad:** Estado reactivo con `ref()` y persistencia de datos mediante `watch()`.
- **Propiedades Computadas:** Cálculo automático de métricas e interpretación de patrones con `computed()`.
- **Manejo de Eventos y Formularios:** Captura de eventos `@submit.prevent` y `@click`.
